Descripción del Sistema de EasyLabTools 
 
Introducción 
EasyLabTools es un sistema integral de gestión de inventario orientado a entornos de 
laboratorio, diseñado para garantizar el control preciso, la trazabilidad completa y la 
administración segura de equipos, insumos y materiales. El sistema centraliza la 
información operativa relacionada con existencias, movimientos, usuarios y 
auditoría, permitiendo a la organización mantener un registro confiable de todos los 
recursos físicos y de las actividades realizadas sobre ellos. 
La plataforma busca resolver problemas comunes en la gestión manual o dispersa de 
inventarios, tales como pérdidas de material, inconsistencias en los registros, falta de 
trazabilidad, errores humanos y ausencia de controles de seguridad. A través de 
procesos automatizados, validaciones de negocio y registros auditables, 
EasyLabTools asegura integridad de datos, control de permisos por roles y visibilidad 
operativa en tiempo real. 
El sistema está concebido como una solución modular, escalable e independiente de 
tecnología, lo que permite su implementación en distintos entornos (web, escritorio o 
híbrido) sin alterar sus reglas de negocio fundamentales. Su arquitectura favorece la 
mantenibilidad, la extensibilidad futura y la integración con otros sistemas 
institucionales. 
Entre sus capacidades principales se incluyen: 
• 
Gestión estructurada de inventario 
• 
Registro de entradas, salidas y ajustes 
• 
Generación de reportes técnicos 
• 
Administración de usuarios y permisos 
• 
Auditoría completa de operaciones 
• 
Configuración de parámetros del sistema 
Este documento presenta la especificación funcional y técnica necesaria para 
reconstruir el sistema desde cero, preservando todas sus capacidades operativas y 
reglas de negocio. La especificación está diseñada para servir como guía de 
desarrollo, referencia técnica y base de validación del sistema final.

 Base de Datos SQL – EasyLabTools 2.0 

 
 
 1. Tabla: roles 
CREATE TABLE roles ( 
    id_rol SERIAL PRIMARY KEY, 
    nombre VARCHAR(50) NOT NULL UNIQUE, 
    descripcion TEXT 
); 
 
 
 2. Tabla: permisos 
CREATE TABLE permisos ( 
    id_permiso SERIAL PRIMARY KEY, 
    nombre VARCHAR(100) NOT NULL UNIQUE, 
    descripcion TEXT 
); 
 
 
 3. Tabla: rol_permiso 
CREATE TABLE rol_permiso ( 
    rol_id INT NOT NULL, 
    permiso_id INT NOT NULL, 
    PRIMARY KEY (rol_id, permiso_id), 
    FOREIGN KEY (rol_id) REFERENCES roles(id_rol), 
    FOREIGN KEY (permiso_id) REFERENCES permisos(id_permiso) 
); 
 
 
 4. Tabla: usuarios 
CREATE TABLE usuarios ( 

    id_usuario SERIAL PRIMARY KEY, 
    nombre VARCHAR(100) NOT NULL, 
    usuario VARCHAR(50) NOT NULL UNIQUE, 
    contrasena VARCHAR(255) NOT NULL, 
    rol_id INT NOT NULL, 
    estado VARCHAR(10) NOT NULL DEFAULT 'activo', 
    fecha_creacion TIMESTAMP DEFAULT CURRENT_TIMESTAMP, 
    FOREIGN KEY (rol_id) REFERENCES roles(id_rol) 
); 
 
 
 5. Tabla: categorias 
CREATE TABLE categorias ( 
    id_categoria SERIAL PRIMARY KEY, 
    nombre VARCHAR(100) NOT NULL UNIQUE, 
    descripcion TEXT 
); 
 
 
 6. Tabla: proveedores 
CREATE TABLE proveedores ( 
    id_proveedor SERIAL PRIMARY KEY, 
    nombre VARCHAR(150) NOT NULL, 
    contacto VARCHAR(150), 
    telefono VARCHAR(50), 
    email VARCHAR(150) 
); 
 

 
 7. Tabla: ubicaciones 
CREATE TABLE ubicaciones ( 
    id_ubicacion SERIAL PRIMARY KEY, 
    nombre VARCHAR(100) NOT NULL UNIQUE, 
    descripcion TEXT 
); 
 
 
 8. Tabla: inventario 
CREATE TABLE inventario ( 
    id_item SERIAL PRIMARY KEY, 
    codigo VARCHAR(50) NOT NULL UNIQUE, 
    nombre VARCHAR(150) NOT NULL, 
    descripcion TEXT, 
    categoria_id INT NOT NULL, 
    proveedor_id INT, 
    ubicacion_id INT NOT NULL, 
    cantidad INT NOT NULL CHECK (cantidad >= 0), 
    estado VARCHAR(10) DEFAULT 'activo', 
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP, 
    FOREIGN KEY (categoria_id) REFERENCES categorias(id_categoria), 
    FOREIGN KEY (proveedor_id) REFERENCES proveedores(id_proveedor), 
    FOREIGN KEY (ubicacion_id) REFERENCES ubicaciones(id_ubicacion) 
); 
 
 
 9. Tabla: tipos_movimiento 
CREATE TABLE tipos_movimiento ( 

    id_tipo SERIAL PRIMARY KEY, 
    nombre VARCHAR(20) NOT NULL UNIQUE 
); 
Datos iniciales: 
INSERT INTO tipos_movimiento (nombre) VALUES 
('ENTRADA'), 
('SALIDA'), 
('AJUSTE'), 
('TRANSFERENCIA'); 
 
 
 10. Tabla: movimientos 
CREATE TABLE movimientos ( 
    id_movimiento SERIAL PRIMARY KEY, 
    item_id INT NOT NULL, 
    tipo_movimiento_id INT NOT NULL, 
    cantidad INT NOT NULL CHECK (cantidad > 0), 
    usuario_id INT NOT NULL, 
    fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP, 
    observacion TEXT, 
    FOREIGN KEY (item_id) REFERENCES inventario(id_item), 
    FOREIGN KEY (tipo_movimiento_id) REFERENCES tipos_movimiento(id_tipo), 
    FOREIGN KEY (usuario_id) REFERENCES usuarios(id_usuario) 
); 
 
 
 11. Tabla: auditoria 
CREATE TABLE auditoria ( 

    id_evento SERIAL PRIMARY KEY, 
    usuario_id INT, 
    accion VARCHAR(100) NOT NULL, 
    detalle TEXT, 
    fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP, 
    ip_equipo VARCHAR(100), 
    FOREIGN KEY (usuario_id) REFERENCES usuarios(id_usuario) 
); 
 
 
 12. Tabla: reportes 
CREATE TABLE reportes ( 
    id_reporte SERIAL PRIMARY KEY, 
    usuario_id INT, 
    tipo VARCHAR(100), 
    parametros TEXT, 
    fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP, 
    FOREIGN KEY (usuario_id) REFERENCES usuarios(id_usuario) 
); 
 
 
 13. Tabla: configuracion 
CREATE TABLE configuracion ( 
    id_config SERIAL PRIMARY KEY, 
    clave VARCHAR(100) NOT NULL UNIQUE, 
    valor TEXT, 
    descripcion TEXT 
); 

 
 
 Índices recomendados

CREATE INDEX idx_movimientos_fecha ON movimientos(fecha); 
CREATE INDEX idx_auditoria_fecha ON auditoria(fecha);

Registro maestro 
de insumos 
Registrar nombre, código interno, tipo de insumo 
(reactivo, calibrador, control, dispositivo médico, 
material fungible), fabricante, proveedor. 
ISO 15189:2022, cl. 6.6 – Reactivos y 
materiales consumibles; Estándares de 
calidad laboratorios clínicos – Minsalud. 

Registro maestro 
de insumos 
Registrar número de lote, fecha de fabricación (si 
aplica), fecha de vencimiento y condiciones de 
almacenamiento requeridas. 
ISO 15189:2022, cl. 6.6; Decreto 3770 de 
2004 (reactivos de diagnóstico in vitro); 
Resolución 132 de 2006 (Invima). 
Registro maestro 
de insumos 
Registrar número de registro sanitario Invima y 
clasificación (reactivo de diagnóstico in vitro, 
dispositivo médico, medicamento, etc.). 
Decreto 3770 de 2004; Resolución 132 
de 2006; lineamientos Invima sobre 
reactivos de diagnóstico in vitro. 
Gestión de lotes y 
recepción 
Registrar evento de recepción por cada lote: fecha, 
proveedor, cantidad recibida, responsable que recibe. 
ISO 15189:2022, cl. 6.6; Estándares de 
calidad laboratorio clínico – 
Minsalud/INS. 
Gestión de lotes y 
recepción 
Registrar inspección en recepción (estado del 
empaque, integridad, temperatura al recibo si aplica). 
ISO 15189:2022, cl. 6.6; manuales de 
habilitación y calidad de laboratorios 
clínicos (INS, Minsalud). 
Gestión de lotes y 
recepción 
Registrar pruebas de aceptación/verificación del lote 
antes de uso (resultado, fecha, responsable). 
ISO 15189:2022, cl. 6.6; Estándares de 
calidad laboratorios clínicos. 
Estado del insumo 
Permitir marcar cada lote con estado: “en 
cuarentena”, “aceptado”, “rechazado”, “vencido”, “en 
retiro/recall”. 
ISO 15189:2022, cl. 6.6 (control de 
insumos no conformes); Estándares de 
calidad lab. clínico. 
Estado del insumo 
Bloquear el uso de insumos en estado “rechazado” o 
“vencido” en los módulos de consumo/uso. 
ISO 15189:2022, cl. 6.6; Resolución 3100 
de 2019 (condiciones de insumos). 
Control de 
inventario 
Registrar movimientos de inventario: entradas, 
salidas, ajustes, devoluciones, descartes, con fecha, 
cantidad y usuario. 
ISO 15189:2022 (registros y trazabilidad); 
Estándares de calidad laboratorios 
clínicos; Resolución 3100 de 2019. 
Control de 
inventario 
Configurar niveles mínimos y máximos por insumo y 
generar alertas de “por debajo del mínimo”. 
ISO 15189:2022, cl. 6.6 (gestión de 
inventario); manuales de 
habilitación/INS. 
Control de 
inventario 
Generar alertas de vencimiento próximo (p. ej. X días 
antes) y de insumos vencidos en stock. 
ISO 15189:2022, cl. 6.6; Estándares de 
calidad laboratorios; normas de 
bioseguridad. 
Control de 
inventario 
Soportar lógica FEFO/FIFO para la sugerencia de uso 
de lotes (usar primero lo que vence antes). 
ISO 15189:2022, cl. 6.6 (minimizar riesgo 
de uso de productos vencidos). 
Trazabilidad con 
pruebas 
Registrar, por cada salida/uso de insumo, el 
servicio/sección, equipo/analizador o tipo de prueba 
en el que se va a usar. 
ISO 15189:2022 (trazabilidad de 
reactivos hacia resultados); Estándares 
de calidad laboratorio clínico. 
Trazabilidad con 
pruebas 
Permitir consultar qué lotes se usaron en un rango de 
fechas, área o tipo de examen, para análisis de no 
conformidades o recall. 
ISO 15189:2022 (sistema de gestión de 
la calidad, trazabilidad); lineamientos 
INS.

Resolución 544 de 2023 (autoevaluación

(existencia, suficiencia y conservación de insumos). 
Resolución 3100 de 2019, arts. sobre 
habilitación; Resolución 544 de 2023 
(art. 7 modificado – autoevaluación). 
Soporte a 
habilitación 
(3100/544) 
Permitir extraer reportes para visitas de verificación 
(historial de inventario, consumo, descartes por fecha 
y responsable). 
Resolución 3100 de 2019 y 544 de 2023 
(verificación); Manual de verificación de 
condiciones. 

Reactivos INVIMA 
Registrar datos específicos requeridos por INVIMA: 
fabricante, país de origen, presentación, condiciones 
críticas de conservación. 
Decreto 3770 de 2004; Resolución 132 
de 2006; guías Invima. 
Reactivos INVIMA 
Identificar en el sistema si el producto tiene 
restricciones de uso (por ejemplo, uso exclusivo en 
laboratorio clínico, no uso en punto de atención, etc.). 
Decreto 3770 de 2004; lineamientos 
Invima. 
Bioseguridad y 
residuos 
Clasificar los insumos según riesgo (inflamable, 
corrosivo, tóxico, biológico, etc.) para fines de 
almacenamiento y disposición final. 
Normas de bioseguridad en 
laboratorios; normativa de residuos 
hospitalarios (p. ej. lineamientos citados 
por INS/Minsalud). 
Bioseguridad y 
residuos 
Registrar salidas por disposición final/destrucción, 
indicando método de eliminación y proveedor/gestor 
de residuos. 
Normativa de residuos hospitalarios y 
similares; políticas internas de 
bioseguridad. 
Gestión de 
proveedores 
Mantener un maestro de proveedores con datos de 
contacto, productos suministrados, tiempos de 
entrega y observaciones. 
ISO 15189:2022 (gestión de compras y 
proveedores); Estándares de calidad 
laboratorio clínico. 
Gestión de 
proveedores 
Registrar evaluaciones de desempeño de 
proveedores (cumplimiento de tiempos, calidad de 
productos, incidentes). 
ISO 15189:2022 (evaluación de 
proveedores); Manuales de calidad del 
laboratorio. 
Seguridad de la 
información 
Definir roles de usuario (almacén, laboratorio, 
dirección de calidad, auditor) y permisos 
diferenciados por módulo. 
ISO 15189:2022 (gestión de registros y 
confidencialidad); buenas prácticas de 
SGSI. 
Seguridad de la 
información 
Mantener trazabilidad de usuario en cada 
movimiento (quién creó, modificó o eliminó un 
registro y cuándo). 
ISO 15189:2022 (trazabilidad de 
registros); Resolución 3100/2019 
(responsabilidad y soporte documental). 
Seguridad de la 
información 
Implementar control de acceso (usuario/contraseña, 
idealmente autenticación por roles) y registro de 
sesiones. 
ISO 15189:2022 (seguridad de la 
información y registros); políticas 
institucionales de TI. 
Reportes y 
auditoría 
Generar reportes de consumo por periodo, servicio y 
tipo de insumo, para análisis de costos y 
planificación. 
ISO 15189:2022 (mejora continua, uso 
de datos); Estándares de calidad 
laboratorio clínico. 
Reportes y 
auditoría 
Generar reportes de no conformidades relacionadas 
con insumos (lotes rechazados, retirados, incidentes). 
ISO 15189:2022 (gestión de no 
conformidades); manual de calidad 
institucional.
